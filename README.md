# AI-Based Software Requirements Specification (SRS) Quality Analyzer

## 📖 Overview
The **AI-Based Software Requirements Specification (SRS) Quality Analyzer** is an AI-powered system designed to improve the quality of Software Requirement Specification (SRS) documents. It uses Artificial Intelligence (AI) and Natural Language Processing (NLP) to identify ambiguous, duplicate, conflicting, inconsistent, and missing requirements. The system generates a quality assessment report with suggestions to help software teams create clear, complete, and reliable requirement documents before development begins.

## 🎯 Objectives
- Improve the quality of SRS documents.
- Detect ambiguous and conflicting requirements.
- Identify duplicate and missing requirements.
- Generate a quality score for each SRS.
- Provide recommendations to improve requirement clarity.

## ✨ Features
- Upload SRS documents (PDF, DOCX, TXT)
- AI-based requirement analysis
- Ambiguity detection
- Duplicate requirement detection
- Conflict detection
- Missing requirement identification
- Quality score generation
- Report generation
